# STYLE-CORE

Переиспользуемый визуальный фундамент платформы ЕГЭ: тёмная тема,
акцентный неоновый цвет, стекло, флипперы, пилюли. Собран так, чтобы
его можно было целиком скопировать в новый Next.js проект и за
несколько минут получить тот же стиль под другой продукт.

## Из чего состоит

```
shared/
  styles/
    tokens.css     ← ЕДИНСТВЕННОЕ место для смены палитры
    effects.css     ← .glass-card, .exam-panel, keyframes
  ui/
    GlassCard.tsx        блок-стекло
    ExamPanel.tsx         тёмная панель верхнего уровня
    DigitStrip.tsx        ряд ячеек-цифр (бланк ответов, счётчик, код)
    SignalDot.tsx          пульсирующая точка-индикатор
    Pills.tsx                ряд круглых пилюль-номеров (пагинация)
    RevealButton.tsx         пилюля-спойлер (показать/скрыть значение)
    Flipper.tsx               два слайда бок о бок, свайп/программно
    ExpandingBubble.tsx        пузырь → панель (FAB-меню)
  hooks/
    useSwipeGesture.ts          touch-события → onSwipeLeft/onSwipeRight
```

## Как развернуть в новом проекте

1. Скопировать папки `shared/styles` и `shared/ui` (+ `shared/hooks`,
   если нужны флипперы/свайпы) в новый Next.js проект.
2. Подключить в `app/globals.css`:
   ```css
   @import "tailwindcss";
   @import "../shared/styles/tokens.css";
   @import "../shared/styles/effects.css";
   ```
3. Поставить зависимости, которых требуют компоненты:
   `framer-motion`, `lucide-react`.
4. Поменять один цвет в `tokens.css` (`--signal`) — и вся тема
   перекрашивается: свечения, границы, активные состояния.
5. Собирать страницы из `GlassCard` / `ExamPanel` / `Flipper` /
   `Pills` вместо того, чтобы писать стекло и свечения заново.

## Принцип

Все визуальные эффекты (цвет, свечение, блюр, радиусы, тайминги)
живут только в CSS-переменных `tokens.css`. Компоненты в `ui/`
ничего не знают про конкретный продукт (ЕГЭ, информатика, задания) —
только про форму: "стекло", "пилюля", "флиппер". Бизнес-логику и
контент компонуй поверх них в `features/`.

Если в новом проекте нужен другой акцент — не трогай `ui/`, меняй
только `tokens.css`. Если нужен новый визуальный примитив — добавляй
его в `ui/` так же безымянно-обобщённо, как остальные, а не как
"кнопка ответа для ЕГЭ".
